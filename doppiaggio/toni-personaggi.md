# I toni dei personaggi

> Il tono di ogni battuta è ricavato dal contesto in cui si dice (chi parla, a chi, che cosa è
> appena successo). Si corregge in `toni.json`, poi `python strumenti/doppiaggio.py blocchi`
> riscrive i blocchi. In AI Studio ogni tono è un blocco di parlato con il suo stile.

| Tono | Stile (da incollare in inglese) |
|---|---|
| calmo | calm, even |
| asciutto | dry, curt |
| stanco | tired, weary |
| diffidente | wary, guarded |
| minaccioso | quietly menacing |
| affabile | affable, friendly on the surface |
| rabbia trattenuta | tightly controlled anger |
| paura | frightened, unsteady |
| tristezza | sad, subdued |
| tenero | tender, gentle |
| sollievo | relieved, a little lighter |
| felice | happy, bright |
| ironico | wry, ironic |
| canzonatorio | teasing, mocking |
| amaro | bitter, resigned |
| commosso | moved, voice catching |
| ansioso | eager, anxious |
| deciso | firm, resolute |
| incerto | unsure, searching for the words |
| febbrile | weak and feverish, trying to sound fine |
| grave | grave, slow, weighing each word |
