# La release 1.18.2

## In breve
Pubblicata la release **v1.18.2** (la prima dopo la 1.14.0, del 15 ottobre): raccoglie le versioni 1.15.0 – 1.18.1, che non ne avevano avuto una propria, e ripubblicata la versione web su GitHub Pages. Il trailer è quello rifinito nelle sei fasi del piano 07; il resto è il pacchetto di correzioni 1.15.0 e i dodici residui della 1.16.0. Il sito di FAVELLA 1 si risincronizza in una sessione a parte, solo se Simone lo dice (brief pronto).

## Contesto
Il prompt della sessione di chiusura metteva il rilascio all'ultimo posto, con condizioni precise; Simone ha ordinato di includerlo («bozza prima, poi si pubblica»). Il tag `v1.18.2` punta a `d467499`, il commit di testa.

## Lavoro fatto
- **Condizioni, una per una.** Albero pulito; `versione.mjs verifica --rilascio` ok (gioco 1.18.2, motore 1.5.0, formato salvataggi 1); i dieci collaudi di `collaudo/` verdi (finali, mirate, salvataggi, scorte, interfaccia, fili, giocate, testo, conferme, pulsanti), `tsc` e `npm run build` verdi; push fatto e CI verde sul commit di testa (`gh run list`).
- **La bozza.** Il workflow «Rilascio» lanciato da `gh` con `bozza: true` (5 min 41 s: verifica, collaudo completo, pacchetti Windows e Linux autoverificati, release). Allegati: installer Windows (120.051.268 byte), portatile (119.813.457), AppImage (134.765.045), deb (107.940.872), blockmap, `latest.yml`, `latest-linux.yml`.
- **I controlli sulla bozza.** Gli `sha512` di `latest.yml` e di `latest-linux.yml` combaciano con quelli calcolati sui file scaricati in una cartella temporanea (installer Windows e AppImage; dimensioni uguali a quelle dichiarate). Il portatile scaricato, lanciato con `--autoverifica` e `VIAGGIATORE_SALVATAGGI` su una cartella temporanea (mai nei Documenti di Simone), esce con codice 0 in 6 s.
- **Le note.** Il workflow prende dal CHANGELOG la sola sezione 1.18.2: le note della bozza sono state riscritte (`gh release edit --notes-file`) con un «In breve» e le sezioni 1.18.2 … 1.15.0 una dopo l'altra, più la tabella dei file e l'avviso sugli eseguibili non firmati: chi aggiorna dalla 1.14.0 legge tutto ciò che cambia.
- **La pubblicazione.** `gh release edit v1.18.2 --draft=false`: «Latest». L'indirizzo che usa l'aggiornamento automatico (`releases/latest/download/latest.yml`) serve la 1.18.2; l'installer risponde 200 con la dimensione giusta.
- **Pagine.** Il workflow «Pagine» lanciato dopo l'ok di Simone, concluso con successo: la versione web è la 1.18.2.
- **Il brief per FAVELLA1** (`sviluppo/brief-favella1-risincronizzazione.md`): il segnaposto `VERSIONE_RILASCIATA` è ora 1.18.2; verificato che dalla 1.14.0 cambiano solo tre `.fav` (`sistemi`, `z2-piana`, `z7-guado`) e nessun file di `motore/`; aggiunta la nota sul nuovo carattere (`app/public/fonts/`) e sul trailer, che sul web vale come sul desktop.
